## Data sources

| Source | Used for | Terms / notes |
|---|---|---|
| [NIST National Vulnerability Database (NVD) API](https://nvd.nist.gov/developers) | CVE records, CVSS scores, CWE and product data | Required notice: *This product uses data from the NVD API but is not endorsed or certified by the NVD.* |
| [CISA Known Exploited Vulnerabilities catalog](https://www.cisa.gov/known-exploited-vulnerabilities-catalog) | Which CVEs are exploited in the wild | US government work |
| [FIRST EPSS](https://www.first.org/epss/) | Exploit-probability scores | Free to use; see FIRST's EPSS usage guidance |

| Wikipedia and linked news articles | Sources cited in lessons | Linked, not copied |

## News feeds

Headlines, short snippets and links come from the public RSS/Atom feeds of: BleepingComputer, The Hacker News, The Record, Krebs on Security, SecurityWeek, Dark Reading, The Register, Graham Cluley, Schneier on Security, SANS Internet Storm Center, UK NCSC and CISA. Every story links to the original publisher, and full articles are never reproduced. "What this means" explanations are original, AI-drafted and human-reviewed.

## Code dependencies

None at runtime. The build uses only the Python standard library; tests use Python's `unittest` and Node's built-in test runner.
